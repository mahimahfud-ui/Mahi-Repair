# Mahi Repair Cloud design-system gallery

Open `index.html` in a modern browser. It demonstrates the admin CSS components, responsive shell, dialogs, toasts and JSON validation. `tokens.css` defines design tokens and `components.css` imports it.

**Demo only:** the metrics, devices, test results, tool rows and publishing messages are placeholders. The page does not connect to Supabase or the Android app. Wire controls to real application handlers before using any of these patterns in production.

Fonts are loaded from Google Fonts when online and fall back to system fonts.
